⚙️ Konfiguracja API SafeCube

Agregator oceaniczny (COSCO, Maersk i inne) — najtańszy per kontener. Klucz z app.safecube.ai.

⚙️ Konfiguracja API ShipsGo

Agregator oceaniczny, model kredytowy (1 kredyt = 1 kontener do końca rejsu). Klucz (authCode) wygenerujesz w panelu shipsgo.com → sekcja API.

⚙️ Konfiguracja API TrackCargo

Agregator oceaniczny (COSCO, Maersk i inne). Klucz znajdziesz w panelu na trackcargo.co.

⚙️ Konfiguracja API Maersk

Bezpośredni tracking Maersk (wymaga konta firmowego). Zarejestruj aplikację i subskrybuj „Track & Trace" na developer.maersk.com.
